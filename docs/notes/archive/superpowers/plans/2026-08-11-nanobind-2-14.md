# Nanobind 2.14 Development-Tool Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the `check_models` development-time nanobind stub generator from 2.13.0 to 2.14.0 while leaving MLX's build-time pin unchanged.

**Architecture:** Keep nanobind as an exact development dependency because its generated stub layout can vary by version. Use the repository's dependency-sync and stub-validation tooling to propagate and verify the pin, then run the complete quality gate.

**Tech Stack:** Python 3.13, pip/PEP 621, nanobind stubgen, pytest, Ruff, mypy, ty, pyrefly.
